# Changelog

## 0.1.0 (2026-11-23)

* First release.
* MelonLoader mod that reads Muse Dash IL2CPP objects by name and writes
  `%LOCALAPPDATA%\MuseDashTrak\status.json`.
* `mdt-status.exe` bridge that prints one line for NekoTrak's `${...}` custom
  status.
* Installer that sets up MelonLoader, the mod and the NekoTrak status item, and
  can uninstall again.
* Configurable text via `format.txt` (song, level, difficulty, accuracy, score,
  combo, elapsed time).
* `selfcheck.cmd` and `simulate.cmd` diagnostics.
